# Работа с репозиторием

Проект содержит Android-приложение и самостоятельную React PWA в `web/`.
Инструкции: [Android](../README.md), [PWA](../web/README.md).

## После клонирования

Для Android откройте корень проекта в Android Studio и укажите локальный
Android SDK. Файл `local.properties` создаётся на вашей машине и не хранится
в Git. Gradle Wrapper включён в репозиторий; настройки Gradle запрашивают
JDK 25 для демона, целевой байткод приложения — Java 17.

Для веб-версии требуется Node.js 22.12+:

```sh
cd web
npm ci
npm test
npm run build
npm run preview
```

Для браузерных тестов установите браузеры Playwright согласно `web/README.md`.
Исходный каталог, фотографии и lock-файл включены: скачивать медиа заново
для обычной сборки не нужно.

## Что не загружается в Git

- локальные настройки SDK и IDE, кэши Gradle и Kotlin;
- зависимости `node_modules`, сборки Android и `web/dist`;
- ZIP веб-сборки, отчёты тестов, журналы;
- ключи подписи, `.env`, локальные базы и резервные копии пользователей.

Не храните персональную историю тренировок и секреты в исходниках.
Публикация кода на GitHub не разворачивает сайт: HTTPS-хостинг PWA
настраивается отдельно. Android и PWA пока не синхронизируют данные.

## Права на материалы

репозитория само по себе не предоставляет лицензию на его использование.
Сторонние фотографии имеют собственные условия: см. [источники медиа](exercise-media.md)
и включённые копии `LICENSE.txt`. Не заменяйте их общей лицензией проекта.
