# Body Build

Android-приложение и React PWA для личных тренировок. Инструкции по
клонированию, составу репозитория и локальным данным: [Работа с репозиторием](docs/repository.md).

## Веб-версия для iPhone

В папке [`web`](web/README.md) находится React PWA: программы, свободные
тренировки, офлайн-фотографии, история и прогресс. Готовая веб-сборка —
`web/dist`, архив — `web/body-build-pwa.zip`.
Приложение опубликовано: [Body Build](https://body-build-gadxx.pages.dev/).
Хостинг — Cloudflare Pages. Workflow `Deploy Body Build` публикует веб-версию
после push в `main`, когда настроен секрет Cloudflare; см. [инструкцию](web/README.md).
Android и веб-версия пока хранят записи независимо.

Нативный офлайн-планировщик тренировок для Android. Приложение собирает объяснимую программу гипертрофии по уровню пользователя, графику, времени, оборудованию и мышечным приоритетам.

## Что уже реализовано

- главная с выбором режима: тренировка по плану или свободная тренировка без генерации;
- детерминированный чистый Kotlin-генератор;
- full body и split-шаблоны для 1–6 дней;
- подходы, повторения, RIR, отдых и расчёт длительности;
- глубокая анатомическая разметка и недельное покрытие;
- локальные профиль, каталог и активный план через Room;
- DataStore для небольших настроек;
- каталог из 133 упражнений с обновлением уже установленной базы, отдельным EZ-грифом, поиском по названию/мышцам и фильтрами;
- unit-тесты генератора и валидатора.
- запуск тренировки с записью повторений и веса после каждого подхода;
- таймер отдыха и общее время тренировки, восстанавливаемые после закрытия приложения;
- профиль с историей, подходами, тоннажом и сохранёнными программами;
- прогресс по подходам и состояниям мышц: выполнено, сейчас и впереди.
- удаление программ и записей истории, отмена текущей тренировки и пропуск упражнения;
- подстановка результатов прошлого выполнения и силовой индекс прогрессии;
- интерактивные графики прогрессии с периодами «Последняя», «Неделя» и «Месяц»;
- офлайн-фотографии двух позиций упражнения с переключением и увеличением; источник и отличия вариантов описаны в [документации медиа](docs/exercise-media.md);
- отдельный тоннаж каждой тренировки и автоматический учёт веса тела.
- свободная тренировка: добавление упражнений и подходов по ходу занятия, ручное завершение и общая статистика;
- история с выбором занятий галочками и анализом фактической нагрузки по выбранным записям;
- редактирование роста и веса в профиле без изменения старых записей.

> Коэффициенты стимула в seed-каталоге являются продуктовой моделью, а не медицинским измерением. Перед публичным выпуском они и техника упражнений должны пройти экспертную редактуру.

## Запуск

1. Установить Android Studio с Android SDK 37. Gradle использует JDK 25 (настроено в `gradle/gradle-daemon-jvm.properties`); целевой байткод приложения — Java 17.
2. Открыть корень проекта и дождаться Gradle Sync.
3. Запустить конфигурацию `app` на устройстве или эмуляторе с Android 7.0+.

Проверки из терминала:

```bash
./gradlew test
./gradlew :app:assembleDebug
```

## Архитектура

`core:model` не зависит от Android. `domain:generator` и `domain:validation` — чистые Kotlin-модули. Android-слои общаются с данными через репозитории, а интерфейс получает неизменяемое состояние из `MainViewModel`.

Основной каталог и дополнительные варианты описаны в `SeedCatalog` и `ExtendedCatalog`. Фотографии встроены в приложение. Следующий контентный этап — экспертная проверка коэффициентов и дальнейшее расширение каталога.

Свободный режим и правила учёта: [Описание и сценарии проверки](docs/free-workout.md).

Подробности подбора и ограничений: [Алгоритм генерации](docs/generator.md). После обновления приложения нажмите «Пересобрать»: сохранённый план не перезаписывается автоматически.
